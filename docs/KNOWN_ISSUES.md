# 已知問題

## 尚待實機回歸

LINE＋LINE 輸出 LINE；直線兩頂點組合輸出兩頂點 LWPOLYLINE；較複雜線段／聚合線組合使用取樣聚合線；涉及真正曲線時輸出 SPLINE。不是 3D LOFT 實體或曲面建模指令。

## 使用限制
